FORECASTING / CLASSIFICATION

Predictive AI

The analyst. Learns patterns from historical examples and returns a probability, score, or forecast.

How it works

Features such as orders, temperature, or account activity are passed into a trained model. The model estimates an outcome and is monitored against reality.

SYNTHESIS / CREATION

Generative AI

The drafting partner. Creates text, code, images, audio, or other artifacts from instructions and context.

How it works

A model turns a prompt into tokens, predicts a likely next token, and repeats the process until it reaches a stopping point. Context and review determine usefulness.

GROUNDING / EVIDENCE

RAG Architecture

The evidence layer. Retrieves relevant passages from trusted sources before a language model writes an answer.

How it works

Documents are split into chunks and converted into embeddings. A question searches the index, then the best passages become model context.

02Retrieve facts

03Answer + cite

PRACTICAL EXAMPLE

Searching company policy

An employee asks about parental leave. The assistant finds the current regional policy, quotes the source, and refuses to guess when no evidence exists.

KPI / grounded answer rate

Strategic targets & KPIs

Citation accuracyTime to resolutionAnswer abstention rate

Live workflow / policy assistant

  1. Index approved documents with owners, dates, and access labels.
  2. Retrieve passages using identity and department filters.
  3. Answer briefly with citations and a confidence signal.
  4. Escalate missing or conflicting evidence to a subject expert.

PLANNING / EXECUTION

Agentic AI

The workflow operator. Plans around a goal, calls approved tools, observes results, and stops or escalates within boundaries.

How it works

An orchestration loop gives a model state, tools, permissions, a budget, and stop conditions. Reliable agents are bounded, observable, and reversible.

MAKE AI MORE EFFECTIVE

Better results come from better systems.

Model quality matters, but most practical gains come from the surrounding workflow. Treat AI like a product with a user, an owner, a success measure, and a safe fallback.

01 / Define

Start with a narrow job

Write the user, input, desired output, and “do not do” boundary before choosing a model.

02 / Ground

Give it the right context

Use approved data, retrieval, examples, and clear instructions. More context is not always better context.

03 / Evaluate

Test before launch

Build a representative test set. Measure accuracy, refusal quality, latency, cost, and harmful edge cases.

04 / Observe

Monitor the real workflow

Log versions, prompts, sources, tool calls, corrections, and outcomes without exposing sensitive content.

05 / Improve

Use feedback deliberately

Fix the data, prompt, retrieval, or interface based on failure patterns. Do not fine-tune by instinct.

06 / Govern

Keep humans in control

Require approval for high-impact actions and provide an easy way to correct, appeal, or stop the system.

AI VOCABULARY / THE TERMS BEHIND THE TOOLS

Know what people mean.

Hallucination

A fluent but unsupported or false output. Reduce risk with grounded sources, structured outputs, validation, abstention, and human review.

RISK / VERIFY FACTS

Multi-agent system

Several specialized agents coordinate through messages or a shared state. Use it only when separation of roles improves quality enough to justify extra complexity.

PATTERN / COORDINATE

Plugins & tools

Structured capabilities an AI can request, such as search, a database query, or a calendar action. Validate permissions and arguments on the server.

CAPABILITY / EXECUTE

AI skills / instructions

Reusable instructions, procedures, examples, and constraints that teach a system how to perform a recurring task. Version them like code and test them like prompts.

CONTROL / STANDARDIZE

Foundation model

A broadly trained model adapted to many downstream tasks. It provides general capability; your application supplies the data, policies, and interface.

MODEL / REUSE

Fine-tuning

Additional training on task-specific examples to change behavior or style. It is not the usual solution for keeping fast-changing facts current.
